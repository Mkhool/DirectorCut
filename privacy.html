Privacy policy

Effective November 25, 2026

Scope

This policy describes DirectorCut’s current self-hosted application and this public information website. The project is maintained by Mkhool. The installation operator controls the computers running the studio and publishing service. There is currently no public hosted account-registration service.

Data used by the application

  • Social account and channel identifiers, display names, handles, connection status and granted permissions.
  • OAuth access and refresh tokens, expiry information and client configuration needed to connect and maintain authorized access.
  • Videos, captions, editorial settings, publication schedules and publication results or links that the operator supplies or generates.
  • Operational information needed to diagnose failures and reconcile publication status.

DirectorCut does not request your Google or TikTok password. Authentication takes place with the provider. Currently, YouTube permissions identify the authorized channel and permit future video upload; requesting upload permission does not mean an upload feature is already available.

Use and storage

Data is used to identify the correct destination, maintain connections and operate supported creation and publishing features. The studio exchanges authorization codes and sends the resulting tokens to the configured publishing service. Tokens are stored in that service’s protected secret storage; client configuration and the studio’s service key are stored outside the code repository. Account metadata and media remain on the operator’s configured storage. Backups can contain this information and require the same protection.

The application is designed not to include tokens in its public interface or logs. Local storage permissions do not replace full disk or backup encryption.

Sharing and service providers

Authentication and authorized API requests send the necessary information to Google/YouTube, TikTok or Meta. Supported publishing actions send the selected media and metadata to the chosen platform. DirectorCut does not sell account data or use it for advertising. This information website does not receive the application’s account tokens or videos.

Google’s handling of data is described in the Google Privacy Policy. Other providers’ own policies apply to their services.

Retention and deletion

Connection information is retained while needed for an authorized connection. In the current service, removing a destination through the connection deletion operation deletes its metadata and deletes the stored authorization when no remaining destination references it. Merely choosing “Remove attachment” unlinks the editorial identity; it does not delete the connection or revoke provider access.

To remove all connection data, ask the installation operator to delete the destination from the service and review any remaining grants and backups. Local projects, videos, publication history and backups are managed separately and are not automatically erased by disconnection. A completed publication remains on the platform until deleted there. The current application has no universal automatic deletion deadline for all local content.

Revoke provider access

You can revoke Google access through your Google Account permissions. For TikTok, use the account’s security settings to manage connected apps. Revocation prevents further authorized requests but does not automatically erase copies already stored locally; request local deletion separately.

This website

These static pages are hosted on GitHub Pages. They contain no analytics scripts, advertising, forms or embedded platform widgets. GitHub may process technical request information under the GitHub Privacy Statement. Following an external link takes you to that provider’s service.

Contact and requests

For access, correction or deletion questions, contact your installation operator. To reach the project maintainer, open a general privacy request. This issue tracker is public: do not include account identifiers, passwords, tokens or other private information. Arrange any necessary private exchange before providing personal data.

Updates will be published here with a revised effective date.
