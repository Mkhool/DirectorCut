DirectorCut is a self-hosted studio for creating, reviewing and preparing original vertical videos, with account management and scheduled Instagram publishing.

Current integration status

Instagram publishing is available in a limited pilot. YouTube account connection is implemented; YouTube video upload is not yet available. TikTok integration is under development and sandbox evaluation; public TikTok publishing is not available.

How it works

  1. Create or import content you own or are authorized to use.
  2. Review the video and select the appropriate editorial identity.
  3. Connect an account through the platform’s authorization screen. Account connection alone does not publish anything.
  4. Use supported publishing features with an explicit destination and schedule.

The studio and publishing service run on computers controlled by the installation operator. This website provides public information only; it does not host the studio or receive authorization tokens.

Contact

Project maintainer: Mkhool. For support or a privacy request, open an issue containing only a general request. Issues are public: never include passwords, tokens, private account data or identity documents.
